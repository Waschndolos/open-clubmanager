# Begriffe

| Begriff | Bedeutung |
|---|---|
| **Abteilung** | Sparte des Vereins, z. B. Fußball oder Turnen. Siehe [Vereinsstruktur](../funktionen/vereinsstruktur.md). |
| **Benutzerrolle** | Was ein Anmeldekonto im Programm darf (Administrator, Kassenwart, Schriftführer, Trainer, Nur lesen). |
| **CAMT.053** | Standardformat für elektronische Kontoauszüge (XML), das fast alle Banken anbieten. |
| **Datenbankdatei** | Die Datei (`.db`), in der alle Vereinsdaten auf deinem Computer gespeichert sind (SQLite-Format). |
| **Einladungscode** | 24-stelliger Code, mit dem ein neues Gerät einem Verein beitritt. 7 Tage gültig, einmal verwendbar. |
| **Geräterolle** | Bei der Zusammenarbeit: welche Datenbereiche ein Gerät bekommt (Vorstand, Kassierer, Schriftführer, Übungsleiter, Gerätewart). |
| **Freistellungsbescheid** | Bescheid des Finanzamts, dass der Verein gemeinnützig und von der Körperschaftsteuer befreit ist. Grundlage für [Zuwendungsbestätigungen](../funktionen/finanzen.md#zuwendungsbestatigungen); 5 Jahre gültig. |
| **Gemeinsamer Ordner / Speicherort** | Der Cloud- oder Netzwerkordner, über den die Geräte bei der Zusammenarbeit Änderungen austauschen. |
| **Gruppe** | Thematische oder organisatorische Zusammenfassung von Mitgliedern, z. B. Trainingsgruppe. |
| **Hauptzahler** | Mitglied, das die Beiträge eines [Haushalts](../funktionen/haushalte.md) bezahlt. |
| **Klärungsbedarf** | Doppelt vergebene eindeutige Werte bei der Zusammenarbeit. Siehe [Klärungsbedarf](../zusammenarbeit/konflikte.md). |
| **Migration (Datenbank)** | Automatische Anpassung der Datenbank an eine neue Programmversion beim Start. Siehe [Updates](../migration/updates.md). |
| **Notfallschlüssel** | Text zum Wiederherstellen der Verwaltung, wenn kein Vorstandsgerät mehr da ist. Siehe [Notfallschlüssel](../zusammenarbeit/notfallschluessel.md). |
| **Rolle (Vereinsstruktur)** | Amt eines Mitglieds im Verein, z. B. Jugendwart. Gibt keine Rechte im Programm. |
| **Rücklastschrift** | Lastschrift, die die Bank des Mitglieds zurückgibt, z. B. mangels Deckung. Siehe [Zahlungsabgleich](../funktionen/finanzen.md#rucklastschriften). |
| **Sammelbestätigung** | Eine [Zuwendungsbestätigung](../funktionen/finanzen.md#zuwendungsbestatigungen) über mehrere Zuwendungen eines Jahres, mit Anlage. |
| **Sicherheitscode** | 6-stelliger Code, den eine beitretende Person dem Vorstand nennt, damit dieser den Beitritt bestätigt. |
| **SEPA-Mandat** | Erlaubnis eines Mitglieds, Beiträge per Lastschrift einzuziehen. |
| **Sync** | Austausch der Änderungen zwischen den Geräten bei der Zusammenarbeit. |
| **Zuwendungsbestätigung** | Spendenquittung nach amtlichem Muster, mit der Spender eine Zuwendung von der Steuer absetzen. Siehe [Zuwendungsbestätigungen](../funktionen/finanzen.md#zuwendungsbestatigungen). |
