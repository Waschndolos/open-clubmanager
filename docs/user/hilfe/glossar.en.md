# Glossary

| Term | Meaning |
|---|---|
| **CAMT.053** | Standard format for electronic bank statements (XML), offered by almost all banks. |
| **Conflict / to resolve** | Unique values assigned twice during collaboration. See [Needs attention](../zusammenarbeit/konflikte.md). |
| **Database file** | The file (`.db`) that stores all club data on your computer (SQLite format). |
| **Device role** | In collaboration: which data areas a device receives (board, treasurer, secretary, coach, equipment manager). |
| **Emergency key** | Text for restoring administration when no board device is left. See [Emergency key](../zusammenarbeit/notfallschluessel.md). |
| **Group** | Thematic or organisational group of members, e.g. a training group. |
| **Invite code** | 24-character code a new device uses to join a club. Valid for 7 days, usable once. |
| **Main payer** | Member who pays the fees of a [household](../funktionen/haushalte.md). |
| **Migration (database)** | Automatic adjustment of the database to a new program version on start. See [Updates](../migration/updates.md). |
| **Returned direct debit** | A direct debit that the member's bank sends back, e.g. for insufficient funds. See [Payment reconciliation](../funktionen/finanzen.md#returned-direct-debits). |
| **Role (club structure)** | A member's position in the club, e.g. youth officer. Grants no permissions in the program. |
| **Safety code** | 6-digit code a joining person tells the board so the board can approve the join request. |
| **Section** | A division of the club, e.g. football or gymnastics. See [Club structure](../funktionen/vereinsstruktur.md). |
| **SEPA mandate** | A member's authorisation to collect fees by direct debit. |
| **Shared folder / storage location** | The cloud or network folder through which devices exchange changes in collaboration. |
| **Sync** | Exchange of changes between the devices in collaboration. |
| **User role** | What a login account may do in the program (Administrator, Treasurer, Secretary, Trainer, Read Only). |
