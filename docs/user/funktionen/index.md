# Funktionen

Alle Bereiche von Open ClubManager im Überblick. Welche du siehst, hängt von deiner [Rolle](../erste-schritte/rollen.md) ab.

| Bereich | Wofür |
|---|---|
| [Übersicht](dashboard.md) | Kennzahlen, nächste Termine, fällige Aufgaben und Hinweise auf einen Blick |
| [Mitglieder](mitglieder.md) | Stammdaten, Adressen, Bankdaten & SEPA, Import/Export, Datenauskunft |
| [Familien & Haushalte](haushalte.md) | Haushalte mit Hauptzahler, Erziehungsberechtigte |
| [Termine](termine.md) | Vereinskalender mit Serien und Kalender-Export |
| [Anwesenheit](anwesenheit.md) | Trainingsbeteiligung erfassen und auswerten |
| [Finanzen](finanzen.md) | Kassenbuch, Mitgliedsbeiträge, SEPA-Lastschrift, Kontoauszug-Import |
| [Inventar](inventar.md) | Gegenstände, Ausleihen, Prüfungen und Wartung |
| [Jubiläen & Ehrungen](ehrungen.md) | Mitgliedsjubiläen, runde Geburtstage, Ehrungen |
| [Qualifikationen](qualifikationen.md) | Lizenzen, Erste Hilfe, Führungszeugnisse mit Ablaufwarnung |
| [Aufgaben](aufgaben.md) | Wer kümmert sich um was |
| [Vereinsstruktur](vereinsstruktur.md) | Abteilungen, Gruppen und Rollen |
| [Verlauf](verlauf.md) | Wer hat wann was geändert |
| [Benutzerverwaltung](benutzer.md) | Konten und Benutzerrollen |
| [Einstellungen](einstellungen.md) | Sprache, Datenbank, Datensicherung |
