# Features

All areas of Open ClubManager at a glance. Which ones you see depends on your [role](../erste-schritte/rollen.md).

| Area | Purpose |
|---|---|
| [Overview](dashboard.md) | Key figures, upcoming events, due tasks and notices at a glance |
| [Members](mitglieder.md) | Master data, addresses, bank details & SEPA, import/export, GDPR data export |
| [Families & households](haushalte.md) | Households with a main payer, guardians |
| [Events](termine.md) | Club calendar with recurring events and calendar export |
| [Attendance](anwesenheit.md) | Record and analyse training attendance |
| [Finances](finanzen.md) | Cash book, member fees, SEPA direct debit, bank statement import |
| [Inventory](inventar.md) | Items, loans, inspections and maintenance |
| [Anniversaries & honors](ehrungen.md) | Membership anniversaries, round birthdays, honors |
| [Qualifications](qualifikationen.md) | Licences, first aid, police clearance certificates with expiry warnings |
| [Tasks](aufgaben.md) | Who takes care of what |
| [Club structure](vereinsstruktur.md) | Sections, groups and roles |
| [History](verlauf.md) | Who changed what and when |
| [User management](benutzer.md) | Accounts and user roles |
| [Settings](einstellungen.md) | Language, database, backup |
