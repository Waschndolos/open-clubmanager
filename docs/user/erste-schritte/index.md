# Erste Schritte

In wenigen Minuten vom Download zum ersten Mitglied:

1. **[Installieren](installation.md)** – Open ClubManager für Windows, macOS oder Linux herunterladen.
2. **[Einrichten](einrichtung.md)** – festlegen, wo die Daten liegen, und das erste Admin-Konto anlegen. Auf Wunsch mit Beispieldaten zum Ausprobieren.
3. **[Anmelden](anmelden.md)** – mit E-Mail und Passwort.
4. **[Oberfläche kennenlernen](oberflaeche.md)** – Navigation, Suche, helles und dunkles Design.
5. **[Benutzer und Rollen](rollen.md)** – weitere Personen anlegen und festlegen, wer was darf.

!!! tip "Erst ausprobieren, dann echte Daten"
    Richte Open ClubManager beim ersten Mal **mit Beispieldaten** ein (ein fiktiver Kitesurf-Verein). So kannst du alle Funktionen gefahrlos testen. Für den echten Betrieb legst du danach eine neue, leere Datenbank an.
