# Getting started

From download to your first member in a few minutes:

1. **[Install](installation.md)** Open ClubManager for Windows, macOS or Linux.
2. **[Set up](einrichtung.md)**: choose where the data is stored and create the first admin account. Optionally with demo data to try things out.
3. **[Log in](anmelden.md)** with your email and password.
4. **[Get to know the interface](oberflaeche.md)**: navigation, search, light and dark mode.
5. **[Users and roles](rollen.md)**: add more people and decide who may do what.

!!! tip "Try first, then use real data"
    The first time, set up Open ClubManager **with demo data** (a fictional kitesurfing club). This lets you test every feature safely. For real use, create a new, empty database afterwards.
