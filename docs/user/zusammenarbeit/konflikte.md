# Klärungsbedarf

Weil jedes Gerät auch offline arbeitet, können zwei Personen gleichzeitig denselben eindeutigen Wert vergeben – zum Beispiel beide die Mitgliedsnummer 1042 für zwei verschiedene neue Mitglieder. Open ClubManager erkennt das und zeigt es unter **Zusammenarbeit → Klärungsbedarf** an (auch über den Sync-Status „Bitte ansehen“).

## Was kann doppelt sein?

- **Mitgliedsnummern**
- **E-Mail-Adressen** von Mitgliedern
- **Namen** von Gruppen, Rollen und Abteilungen

## So löst du es

Für jeden Fall zeigt Open ClubManager, welcher Eintrag den Wert **behält** und welcher **geändert werden muss**. Die Regel: Den Wert behält, wer ihn **zuerst** vergeben hat.

| Fall | Lösung |
|---|---|
| Mitgliedsnummer doppelt | **Nächste freie Nummer vergeben** oder **Nummer selbst wählen** |
| E-Mail-Adresse doppelt | eine neue E-Mail-Adresse eintragen |
| Name doppelt | einen neuen Namen eintragen |

Klicke auf **Übernehmen**. Die Änderung wird an alle verteilt, und der Eintrag verschwindet aus der Liste.

Klären kann das jeder, der für den betroffenen Bereich Schreibrecht hat. Wer nur lesen darf, sieht den Hinweis, kann aber nichts ändern.
