## Ground rules for every migration

1. **Back up first.** Create a [backup](../funktionen/einstellungen.md#backup) and keep it until everything has been checked.
2. **Test first.** Try the switch with a copy or a test database before working with real data.
3. **Check afterwards.** Take samples: is the member count right? Are bank details and entry dates right for a few members?
4. **Delete old data securely.** Don't leave old spreadsheets and exports with member data lying around forever.
