## Grundregeln für jede Migration

1. **Vorher sichern.** Erstelle eine [Datensicherung](../funktionen/einstellungen.md#datensicherung) und bewahre sie auf, bis alles geprüft ist.
2. **Erst testen.** Probiere den Umstieg mit einer Kopie oder einer Testdatenbank, bevor du mit den echten Daten arbeitest.
3. **Danach prüfen.** Stichproben machen: Stimmt die Mitgliederzahl? Stimmen Bankdaten und Eintrittsdaten bei einigen Mitgliedern?
4. **Alte Daten sicher löschen.** Alte Excel-Listen und Exporte mit Mitgliederdaten nicht ewig herumliegen lassen.
