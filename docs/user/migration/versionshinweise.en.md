# Release notes

Normally an update needs [no manual steps](updates.md): the database is adjusted automatically on start.

If a version **exceptionally** needs a manual step (e.g. because an export format changes, a setting has to be set again, or with collaboration all devices must update at the same time), you'll find instructions here.

!!! success "Currently no manual steps needed"
    So far no version has required manual steps when updating.

The full list of changes in each version is on the [releases page](https://github.com/Waschndolos/open-clubmanager/releases).
