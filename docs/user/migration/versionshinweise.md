# Versionshinweise

Normalerweise ist ein Update [ohne Handarbeit](updates.md) möglich: Die Datenbank wird beim Start automatisch angepasst.

Erfordert eine Version **ausnahmsweise** einen manuellen Schritt – z. B. weil sich ein Exportformat ändert, eine Einstellung neu gesetzt werden muss oder bei der Zusammenarbeit alle Geräte gleichzeitig aktualisiert werden müssen –, steht hier eine Anleitung.

!!! success "Aktuell keine manuellen Schritte nötig"
    Bisher gibt es keine Version, die Handarbeit beim Update erfordert.

Die vollständige Liste der Änderungen jeder Version findest du auf der [Release-Seite](https://github.com/Waschndolos/open-clubmanager/releases).
