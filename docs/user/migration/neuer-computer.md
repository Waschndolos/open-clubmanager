# Auf einen neuen Computer umziehen

## Ohne Zusammenarbeit (nur auf diesem Gerät)

1. **Alter Computer:** [Datensicherung erstellen](../funktionen/einstellungen.md#datensicherung) und die `.zip`-Datei auf einen USB-Stick kopieren.
2. **Neuer Computer:** Open ClubManager in derselben oder einer neueren Version [installieren](../erste-schritte/installation.md).
3. Ersteinrichtung mit „Nur auf diesem Gerät“ durchführen, ein vorläufiges Admin-Konto anlegen (**ohne** Testdaten).
4. **Einstellungen → Backup einspielen** → die Sicherung wählen → bestätigen.
5. Open ClubManager **neu starten** und mit deinem **bisherigen** Konto anmelden.
6. Stichproben machen. Wenn alles stimmt: Datenbank und Sicherung auf dem alten Computer **sicher löschen**.

!!! tip "Alternative: Datei kopieren"
    Du kannst auch die Datenbankdatei (`.db`) direkt kopieren und bei der Einrichtung auf dem neuen Computer als Datenbankpfad angeben. Schließe Open ClubManager auf dem alten Computer vorher.

## Mit Zusammenarbeit

Bei der Zusammenarbeit ist ein neuer Computer einfach ein **neues Gerät**:

1. Lass dich vom Vorstand [einladen](../zusammenarbeit/personen-geraete.md#person-einladen) (oder lade dich als Vorstand selbst ein).
2. Auf dem neuen Computer [beitreten](../zusammenarbeit/beitreten.md). Die Daten kommen aus dem gemeinsamen Ordner.
3. Das alte Gerät unter [Personen & Geräte](../zusammenarbeit/personen-geraete.md#gerat-entfernen) **entfernen** (Grund: „Gerät wird nicht mehr genutzt“).

Warte vor dem Entfernen, bis das alte Gerät „Alles synchronisiert“ zeigt – sonst gehen dort noch wartende Änderungen verloren.
